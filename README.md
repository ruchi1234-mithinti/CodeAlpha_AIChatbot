# AI Chatbot

A simple Java console-based AI chatbot developed using rule-based responses and basic NLP-style keyword matching.

## Features
- Interactive chatbot conversation
- Rule-based responses
- Basic NLP-style keyword matching
- Handles common user queries
- Exit command to end chat
- Console-based interface

## Technologies Used
- Java
- OOP Concepts
- String Handling

## Project Structure
- Main.java
- ChatBot.java
- ResponseHandler.java

## How to Run
1. Open the project in IntelliJ IDEA
2. Run Main.java
3. Start chatting with the bot in the console

## Sample Inputs
- hello
- hi
- what is java
- what is your name
- bye
- exit
